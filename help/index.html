Getting your chats into Telegram Archive

Three steps: export a chat from Telegram, put it in your folder, open the folder.

1. Export a chat 2. Put it in your folder 3. Open it Privacy

1. Export a chat from Telegram Desktop

  1. Install Telegram Desktop from desktop.telegram.org. Use the version from Telegram’s own website, not the one from the Mac App Store.
  2. Sign in, and open the chat you want to keep.
  3. Click the ⋮ menu at the top right of the chat, then Export chat history.
  4. Under Format, choose Machine-readable JSON. This matters: it is the format Telegram Archive reads.
  5. Tick the kinds of media you want to keep: photos, videos, voice messages, video messages, stickers, GIFs and files. Raise the size limit if you want long videos too.
  6. Click Export. Telegram saves a folder called ChatExport_ followed by the date, usually in Downloads › Telegram Desktop.

Export each chat on its own, as above. Telegram’s whole-account export (Settings › Advanced › Export Telegram data) packs everything into one file, which Telegram Archive does not read.

2. Put it in your Telegram Archive folder

Make a folder called Telegram Archive wherever you like. Inside it, make a folder called Backups, and inside that, one folder per chat:

Telegram Archive/
  Backups/
    Robin/
      ChatExport_2024-03-01/
        result.json
        photos/  stickers/  …
    Book Club/
      ChatExport_2024-05-01/
        result.json  …
  telegram-archive-config.json    ← your settings, made for you
  1. Make a folder for the chat inside Backups. Name it after the chat.
  2. Move the ChatExport_… folder Telegram made into it.

Exported the same chat again later? Put the new ChatExport_… folder next to the old one, in the same chat folder. Telegram Archive merges them, and uses each photo from whichever export still has it.

On a NAS or a cloud drive? That works. When it starts, Telegram Archive reads only the small result.json files, so nothing large is downloaded. Photos and videos are fetched only as you scroll to them.

3. Open it in Telegram Archive

Open Telegram Archive, press Choose your Telegram Archive folder, and pick the folder from step 2 (the one that has Backups inside it). The first time, it reads your chats and builds an index; after that it opens straight away.

Chrome, Edge Remembers the folder, and saves your settings into it automatically.
Safari, Firefox, Brave You choose the folder on each visit. After changing settings, press Save (bottom left) and put the downloaded telegram-archive-config.json in your Telegram Archive folder, replacing the old one. Closing the tab with unsaved changes asks first.

Privacy

  • Runs in your browser. No account, no sign-in, no tracking, no ads, no cookies.
  • Your archive stays on your device. Chats, photos, stickers and settings never leave it. The page is built so that it cannot send them anywhere.
  • It only reads your exports. The one file it ever writes is telegram-archive-config.json, next to your Backups folder, and only in browsers that allow it.
  • What GitHub sees. This website is hosted on GitHub, so loading it tells GitHub your IP address and which browser you use, as any website would. It never tells GitHub anything about your archive.
